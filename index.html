About this monitor

This page is designed as a lightweight demonstration of auroral kilometric radiation (AKR) observations using Arase PWE-HFA spectra. The front end reads a compact JSON product, so it can be hosted directly on GitHub Pages.

Data status

The repository currently contains a built-in demonstration spectrum. The updater can replace data/akr.json with regularly retrieved CDAWeb/HAPI data.
